Maha Academy — English Adventure, Kindergarten (Letter Sounds Adventure)

This folder is the editable source of KG_English_Adventure.html (one folder up).
Content is generated by not_published/games_generator/eng/make_kg.py; to change words
or questions, edit that script and run it again from the Maha_Academy folder.

Stations: Sound Gate S (snake, sun, sock, star) · A (apple, ant, alligator, astronaut) ·
T (tiger, turtle, tap, tomato) · P (pig, panda, pineapple, pen) · M (moon, map, monkey, milk) ·
Mahir's Treasure Gate (build sat/pat/mat/tap/map, same-or-different first sound, treasure clues).

Preview while editing: open index-dev.html in a browser.
Rebuild the single file: python3 build.py  (writes maha-academy.html — rename it to KG_English_Adventure.html)
